# BaapCollab Master Project Manifest

Generated by Senior System Architect for Cloud Deployment Readiness (March 25, 2026).

---

## 1. ARCHITECTURAL OVERVIEW
- **Project Structure:**
  - `/backend`: FastAPI-based Python microservice.
  - `/frontend`: Next.js (React 19) web application.
- **Tech Stack Versions:**
  - **Python:** 3.11+
  - **FastAPI:** 0.135.2
  - **Node.js:** 18.x / 20.x
  - **Next.js:** 16.1.6
  - **React:** 19.2.3
  - **ORM:** SQLModel (SQLAlchemy 2.0.47)
  - **Styling:** Tailwind CSS v4

## 2. DATABASE SPECIFICATIONS (NEON)
- **SQL Dialect:** PostgreSQL 16
- **Definitions:** SQLModel-mapped entities (`User`, `Post`, `Comment`, `Branch`, `RewardLog`, `CommentUpvote`, `ProjectApplicant`).
- **SSL Implementation:** `sslmode=require` is dynamically enabled for all non-SQLite connections in `backend/database.py`.
- **Migration Engine:** Alembic (`alembic upgrade head`).

## 3. BACKEND DEPLOYMENT DATA (RAILWAY)
- **Start Command:** `uvicorn main:app --host 0.0.0.0 --port ${PORT}`
- **Build Strategy:** Docker-driven (via `backend/Dockerfile`).
- **Required Environment Variables (Keys):**
  - `DATABASE_URL` (Neon PostgreSQL connection string)
  - `RESEND_API_KEY` (Transactional emails)
  - `SECRET_KEY` (JWT signature)
  - `ALGORITHM` (Default: HS256)
  - `GOOGLE_CLIENT_ID` (Placeholder for OAuth)
  - `GOOGLE_CLIENT_SECRET` (Placeholder for OAuth)
  - `FRONTEND_URL` (CORS configuration)

## 4. FRONTEND DEPLOYMENT DATA (VERCEL)
- **Build Command:** `next build`
- **Output Directory:** `.next`
- **API Endpoint Logic:** Uses `NEXT_PUBLIC_API_URL` to point to the Railway backend service.
- **Framework Preset:** Next.js.

## 5. SECURITY & AUTHENTICATION
- **Current Status:** 
  - Full Email/Password Auth with optional OTP verification.
  - Role-Based Access Control (RBAC): `STUDENT`, `ADMIN`, `SUPERADMIN`.
- **JWT Configuration:** 
  - Token-based session management using `HttpOnly` cookie-safe tokens.
  - Implementation via `python-jose` and `passlib[bcrypt]`.
- **CORS Policy:** 
  - Production targets configured for dynamic domain matching (Vercel subdomains + Production domain).
  - Explicitly allowed headers: `Content-Type`, `Authorization`.
